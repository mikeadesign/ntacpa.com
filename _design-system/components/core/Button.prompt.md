Use for any action. Navy primary, hairline secondary, text-only ghost, white inverse on navy.

```jsx
<Button>Request a consultation</Button>
<Button variant="secondary" size="large">View services</Button>
<Button variant="ghost" size="small">Cancel</Button>
<Button variant="inverse">Get in touch</Button>   {/* on navy */}
```

Corners are square — the identity is print-derived. Gold is deliberately not a
button fill: white on gold is 2.1:1 and fails AA.
