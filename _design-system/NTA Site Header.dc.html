Why not the primary lockup

A header band gives a logo 175px. The full lockup needs 320.

The primary lockup's two descriptor lines scale with the whole thing. At 320px wide they set at 9px — the legibility floor. Squeezed into a header they land under 4px and stop being words. Compact solves it by removing them, so the mark, the gold rule, and the name are all still doing their job at header scale.

Why SVG

The letterforms are locked into the file.

Every lockup in brand-assets/svg/ carries its wordmark and descriptor as filled vector paths traced from real Spectral and Archivo outlines. There is no <text> element and no font-family to resolve, which matters because an <img> tag has no access to the host page's webfonts. Earlier versions set the wordmark as live text with a serif fallback — inside an <img> that silently rendered in a wider system serif and clipped the viewBox. Outlines make the header identical on first paint, on a cold cache, and in a PDF.

Set height only and let the width follow the 3.117:1 ratio. A fixed width plus a fixed height will letterbox the lockup inside its own box.

CSS
.site-header { height: var(--header-h); padding-inline: 28px; }
.site-logo img { height: var(--header-logo-h); width: auto;
                 display: block; transition: height .2s ease; }

.site-header[data-sticky] { height: var(--header-h-sticky); }
.site-header[data-sticky] .site-logo img { height: var(--header-logo-h-sticky); }

@media (max-width: 640px) {
  .site-header { height: var(--header-h-mobile); }
  .site-logo img { height: var(--header-logo-h-mobile); }
}
